## Description
This project demonstrates how structured logging and centralized exception handling improve debugging and maintainability in ASP.NET Core APIs.

## Features
- Structured logging using Serilog
- Centralized exception handling using middleware
- Correlation ID tracking for request tracing
- Swagger UI for API testing

## Technologies Used
- ASP.NET Core Web API

- Serilog

GET /api/test/{id}
